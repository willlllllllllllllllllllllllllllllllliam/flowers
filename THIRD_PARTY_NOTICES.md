## Walkway SemiBold

Graham Meade, GemFonts / Typotheticals, created Walkway.
The site uses the original font file without changes.
The project changes only its filename to remove the space.

See [the author notice](assets/LICENSE-Walkway.txt) for the source and the author's public statement.
The notice records provenance, not a new license grant.

## Special Elite

Astigmatic created Special Elite.
The site uses the original font file for the heading, arrows, and small labels.
The font uses the [Apache License 2.0](assets/LICENSE-SpecialElite.txt).

Source: [Google Fonts Special Elite](https://github.com/google/fonts/tree/main/apache/specialelite).

## Art and earlier work

The V2 gardens use original procedural geometry. They do not embed artwork by Zancan.
Zancan's botanical ink work inspired the V2 art direction.
The README preserves the original version's tutorial credits.

The package lockfile records their versions. Their packages contain the relevant notices.
